# Fidel Crossword Ethiopia — Release Candidate 1

Version: **1.0.0+1**

This package is the clean release-candidate source for the first public version.

## Included

- Home screen with Start Game, Learn Fidel, Levels, Challenge Yourself, Settings and About.
- All 33 Fidel family crosswords are included in the correct family order.
- **Level 3 — Mixed Family Challenge** is a separate seven-family crossword using ሀ, ለ, ሐ, መ, ሠ, ረ and ሰ.
- The normal **ሐ family** crossword is preserved immediately after the Level 3 challenge instead of being replaced.
- Purple **Level 4 — Challenge Yourself** remains a separate 33-family ordering challenge.
- Learn Fidel with 231 individual letter recordings, plus later corrected recordings for ሸ, ደ, ጀ and ጸ families.
- Green/red answer feedback, scoring, reset, clear, previous-family and next-family controls.
- Settings with Sound and Larger Text preferences.
- About page and version information.
- iOS and Android project folders included.
