# App Store Handoff

The Flutter source is prepared as version **1.0.0+1**.

Before the final Apple upload, the remaining account-specific steps are:

1. Confirm the Apple Developer Team/signing account in Xcode.
2. Confirm that the Bundle ID in App Store Connect matches `com.fidelcrosswordethiopia.app` (or replace the project ID with the Bundle ID already registered in the account).
3. Add the final approved App Store icon and store screenshots.
4. Create an Archive in Xcode and upload it to App Store Connect.
5. Complete App Store Connect listing, privacy answers, age rating and review information.

No Apple password, certificate, signing key, or payment information is included in this source package.
