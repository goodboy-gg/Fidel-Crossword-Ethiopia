# Fidel Crossword Ethiopia Support

Thank you for using Fidel Crossword Ethiopia.

If you need help with the app, have a question, want to report a problem, or would like to share feedback, please open a support request through the repository's Issues section:

https://github.com/goodboy-gg/Fidel-Crossword-Ethiopia/issues

When reporting a problem, please include a short description of the issue and, if helpful, the device model and iOS version you are using.

Fidel Crossword Ethiopia is an educational app for learning and practising the Ethiopian Fidel alphabet through guided lessons, pronunciation practice, crosswords, and mixed challenges.
